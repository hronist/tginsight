# Предложения по улучшению UX/UI (tginsight)

Этот документ описывает планируемые изменения для решения проблем со сложностью и неочевидностью интерфейса.

## 1. Разделение поиска: RAG vs AI

**Проблема:** Пользователь не понимает, когда он получит просто список сообщений, а когда — ответ от нейросети.
**Решение:** Внедрить переключатель режима прямо в `RagAskBar`.

- **Режим «Поиск» (RAG):** Быстрый семантический поиск. Результат — список карточек. Иконка `Search`.
- **Режим «Ассистент» (AI):** Генерация ответа на основе найденного. Требует API-ключ. Иконка `Sparkles`.
- **Визуал:** Использовать `Tabs` или `ToggleGroup` внутри строки поиска. Если ключ не задан, режим AI заблокирован с подсказкой.

## 2. Карточка сообщения (MessageCard)

**Проблема:** «Не идеально» — вероятно, не хватает воздуха или четкой иерархии.
**Решение:** Освежить дизайн карточки.

- **Типографика:** Увеличить межстрочный интервал для основного текста (`leading-relaxed`).
- **Метаданные:** Сделать ID сообщения и дату менее контрастными, но оставить читаемыми.
- **Группировка:** Если сообщение — часть цепочки (контекст), использовать более мягкую визуальную связь (вертикальная линия слева).
- **Интерактив:** Добавить легкую подсветку при наведении.

## 3. Навигация: Возврат к ленте

**Проблема:** Кнопка «К ленте» неочевидна, смена контекста слишком резкая.
**Решение:** Изменить способ отображения результатов AI.

- **Хлебные крошки (Breadcrumbs):** Показать путь `Лента > [Ваш вопрос]`.
- **Заголовок:** Сделать заголовок `AskResultPanel` более выразительным с явной кнопкой закрытия (крестик) в углу, привычной пользователю.
- **Анимация:** Плавный переход (slide-in) при открытии результатов поиска.

## 4. Модернизация фильтров

**Проблема:** Элементы выглядят стандартно.
**Решение:** Использовать более современные контролы.

- **Период:** Вместо двух `select` использовать единый диапазон (если позволяет библиотека) или более компактные «чипсы» для быстрых периодов (1 мес, 3 мес, все).
- **Авторы:** Автодополнение (combobox) вместо простого текста через запятую.
- **Списки:** Использовать `ScrollArea` для длинных списков авторов.

## План внедрения

1. **MessageCard:** Обновление стилей и типографики.
2. **RagAskBar:** Добавление переключателя режимов.
3. **AskResultPanel:** Редизайн шапки и кнопки выхода.
4. **FiltersPanel:** Обновление селекторов периода и авторов.
